# Asset and Production Notes

This repository provides the final participant-facing video stimuli used in the study.

## Scope of this repository

The repository includes:
- final `.mp4` stimulus videos shown to participants
- structured metadata describing the stimulus set
- brief documentation of the production workflow

The repository does not include editable production source files.

## Source production files

The original production files created in Blender and Adobe After Effects are not redistributed in this repository.

These source files contain proprietary third-party assets licensed from commercial marketplaces. While these assets were legally used to create the final study materials, their licenses do not necessarily permit redistribution of the original editable source files or underlying asset files.

## Production workflow

The final stimulus videos were created in a multi-step workflow:

1. **Scene creation in Blender**
   - Scenario-based traffic scenes were created in Blender.
   - Multiple environmental variants were developed depending on study condition.

2. **Visual XAI adaptation**
   - Visual scene properties were modified for XAI presentation.
   - Materials were adjusted.
   - Scene complexity was reduced where needed.
   - The camera perspective was changed from ego perspective to bird’s-eye view.

3. **Post-production in Adobe After Effects**
   - Final participant-facing videos were assembled in Adobe After Effects.
   - Audio and modality-specific components were integrated during post-production.
   - Final exports were rendered as `.mp4` stimulus files.

## Redistribution limitations

This repository shares the final study stimuli, but it does not redistribute:
- Blender source files
- Adobe After Effects project files
- commercial asset source files
- editable project files containing proprietary third-party content

This decision is intended to make the actual participant-facing materials openly available while respecting redistribution limits associated with licensed third-party assets.

## Reproducibility note

The repository is intended to provide access to the final materials shown to participants.  
It does not provide a full editable reconstruction pipeline because key source components depend on proprietary third-party assets that cannot be openly redistributed within this repository.
